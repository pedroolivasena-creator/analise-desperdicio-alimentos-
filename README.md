# Análise de Dados – Desperdício de Alimentos

## Sobre o projeto

Este projeto tem como objetivo analisar dados relacionados ao desperdício de alimentos, identificando padrões, quantidades desperdiçadas e possíveis fatores associados às perdas.

Foram utilizadas ferramentas de análise de dados e Business Intelligence para transformar os dados coletados em informações que auxiliem na tomada de decisões.

## 1. Coleta de dados

A primeira etapa consistiu na obtenção da base de dados utilizada na análise do desperdício de alimentos.

Os dados foram organizados em uma planilha contendo informações sobre os alimentos, quantidades desperdiçadas e condições de armazenamento.

A base foi importada para o Python, utilizando a biblioteca Pandas, permitindo a leitura, organização e exploração das informações.

Principais variáveis analisadas:

- Nome dos alimentos.
- Quantidade desperdiçada em quilogramas.
- Condições de armazenamento.
- Categorias dos alimentos.
- Demais informações disponíveis na base.

## 2. Modelagem e análise dos dados

O tratamento e a análise dos dados foram realizados utilizando Python.

### Ferramentas utilizadas

- Python: linguagem utilizada para análise dos dados.
- Pandas: tratamento e organização da base de dados.
- Statistics: cálculos estatísticos, como média e mediana.
- Matplotlib: criação de visualizações.
- Plotly: desenvolvimento de gráficos interativos.
- Looker Studio: criação do dashboard para apresentação dos resultados.

### Etapas realizadas

1. Importação e leitura da base de dados.
2. Verificação e tratamento de informações ausentes.
3. Organização das colunas e variáveis.
4. Análise exploratória dos dados (EDA).
5. Cálculo de medidas estatísticas.
6. Identificação dos 50 alimentos com maiores quantidades desperdiçadas.
7. Criação de gráficos para identificar padrões e distribuições.
8. Desenvolvimento de um dashboard interativo no Looker Studio.

### Visualização dos resultados

O Looker Studio foi utilizado para apresentar os resultados por meio de indicadores, gráficos e filtros interativos.

O dashboard permite identificar os alimentos com maiores índices de desperdício, comparar categorias e investigar possíveis relações entre armazenamento e perdas.

## 3. Conclusões

A análise realizada demonstrou a importância da utilização de ferramentas de análise de dados para compreender o desperdício de alimentos.

O Python possibilitou o tratamento, a exploração e a interpretação estatística das informações, enquanto o Looker Studio permitiu transformar os resultados em visualizações interativas e acessíveis.

Com base nos resultados, foram identificadas oportunidades de melhoria relacionadas ao controle de estoque, armazenamento e planejamento de compras.

Entre as principais recomendações estão:

- Priorizar o controle dos alimentos com maiores índices de desperdício.
- Melhorar as condições de armazenamento.
- Evitar compras excessivas.
- Monitorar periodicamente os indicadores de desperdício.
- Utilizar os resultados da análise para apoiar decisões.

Conclui-se que a integração entre Python e Looker Studio proporciona uma abordagem eficiente para transformar dados em informações estratégicas, contribuindo para a redução do desperdício e a otimização de recursos.
